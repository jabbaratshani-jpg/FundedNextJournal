ژورنال معاملات چندچالشی اندروید

ویژگی‌ها:
- ساخت چند چالش با نام، شرکت پراپ و سرمایه اولیه
- ثبت معاملات برای هر چالش جداگانه
- ثبت تاریخ، نماد، جهت معامله، سود/زیان و یادداشت
- محاسبه جمع سود/زیان ثبت‌شده برای هر چالش
- ذخیره محلی روی گوشی

ساخت APK بدون نصب Android Studio:
1) در GitHub مخزن FundedNextJournal را باز کنید.
2) Add file > Upload files را بزنید.
3) تمام محتویات این پوشه را انتخاب و بارگذاری کنید؛ پوشه .github هم باید بارگذاری شود.
4) Commit changes را بزنید.
5) به زبانه Actions بروید، workflow با نام Build Android APK را باز کنید و Run workflow را بزنید.
6) پس از اتمام موفق، در همان اجرای workflow بخش Artifacts، فایل FundedNext-Journal-APK را دانلود کنید.
7) ZIP دانلودشده را باز کنید و app-debug.apk را روی گوشی نصب کنید. ممکن است Android اجازه نصب از منبع ناشناس را بخواهد.

این نسخه APK آزمایشی (debug) برای نصب شخصی است، نه انتشار در Google Play.
